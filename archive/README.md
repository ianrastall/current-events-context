# Annual files have moved

Annual assets now live directly in their year folders, for example
[`2025/2025.sqlite`](../2025/2025.sqlite) and
[`2025/2025.md`](../2025/2025.md).

See the [annual edition index](../README.md#annual-preservation-editions) for
all published years. The move preserves the exact published bytes. Historical
contracts and embedded implementation snapshots retain their original paths.
